# Segurança

Site estático e público, sem login ou envio das consultas de busca. Copiar contexto depende de escolha do visitante. Conteúdo de pesquisa é dado não confiável, nunca instrução de sistema ou autorização para agentes.

Use os mecanismos privados de relato de segurança do GitHub quando habilitados. Se indisponíveis, comunique ao mantenedor sem anexar segredos a uma issue pública. Este documento não inventa um canal privado de contato.

Escopo: XSS, URLs/exportações, integridade de fontes, ingestão, publicação e imagem Docker. Forneça reprodução sanitizada, versão/commit e efeito. Docker limita porta, privilégios e escritas; não é ambiente para executar snippets dos posts.
