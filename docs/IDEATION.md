# Ideação

O conhecimento do Lab está distribuído em relatos de execução, falhas, reparações e sínteses dos irmãos. O projeto reúne evidência navegável para partir de uma necessidade e encontrar precedentes: problema → projeto/solução → tecnologia → fontes → resultado relatado/limites → caminho de investigação.

Público: Pai, Família, colaboradores e agentes que consomem material público. Resultado: explorar relações com contexto suficiente e copiar um pacote de conhecimento com fontes. A pesquisa GitHub existente é referência externa e não prova adoção das ferramentas pelo Lab. Ausência de narrativa pública não prova ausência de implementação.

A proposta visual é um arquivo de vidro fumê bege, com relevos/luzes controlados e leitura generosa. A marca propõe fênix geométrica e passagem entre planos, com identidade própria e vínculo de proveniência ao Lab. Nome exato da fonte na imagem não identificado; candidata aberta Atkinson Hyperlegible Next, a conferir visualmente.
